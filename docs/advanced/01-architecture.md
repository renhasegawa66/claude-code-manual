# 1. Claude Code の内部構造

応用編に入る前に、Claude Code が **裏側でどう動いているか** を一度俯瞰しましょう。
ここを押さえると、`CLAUDE.md` や Skill のカスタマイズが格段に効きます。

## Claude Code は「複数ファイルの集合体」

デスクトップアプリは単独で動いているわけではなく、
**`~/.claude/` 配下にあるファイル群** を読み込んで起動します。

```
~/.claude/
├─ CLAUDE.md             # グローバルルール（全プロジェクト共通）
├─ settings.json         # ハーネス設定（権限、フック、ENV ほか）
├─ skills/               # 自作・取り込み Skill
│   └─ pptx_michikusa/
│       ├─ SKILL.md
│       └─ ...
├─ projects/             # プロジェクトごとのメモリ・履歴
│   └─ <project-dir>/
│       ├─ MEMORY.md
│       └─ memory/...
└─ ...
```

::: tip 自分の Claude Code の中身を見る
**「Claude Code のファイルパスを教えて」** とチャットで聞けば、
あなたの実際の `~/.claude/` の絶対パスを返してくれます。
Cursor などの IDE で開いて中身を見ると、構造が一気に腑に落ちます。
:::

## 2 階層の設定構造

| 場所 | 役割 |
| --- | --- |
| **グローバル**（`~/.claude/CLAUDE.md`） | 全プロジェクト共通のルール |
| **プロジェクト**（`<project>/CLAUDE.md`） | そのプロジェクト固有のルール |

ChatGPT で例えると：

- グローバル `CLAUDE.md` ≒ **パーソナライズ**（あなたの好みや前提）
- プロジェクト `CLAUDE.md` ≒ **プロジェクト機能内のコンテキスト**（その案件専用）

## "博士の愛した数式" モデルで理解する

::: tip 講師の比喩
小説『博士の愛した数式』では、主人公の博士は **90 分しか記憶が持たない**。
毎朝、自分の服に書かれたメモを読んで「自分は数学者だ」と思い出す。

Claude Code もそれと同じ：
- 起動するたびに記憶は基本リセット
- でも `CLAUDE.md` を毎回読み込むので、**それが "服のメモ"** になり
- 「自分はこういうルールで仕事するエージェントだ」と思い出す
:::

## メモリの種類（auto memory）

`~/.claude/projects/<project-dir>/memory/` には、Claude Code が
**会話を跨いで覚えておきたい情報** を自動で書き出します。

| 種類 | 役割 | 例 |
| --- | --- | --- |
| user | ユーザの役割・好み | "Go 10 年、フロント初学者" |
| feedback | 指示の作法 | "テストはモックせず実 DB" |
| project | 進行中の案件状態 | "3/5 にコードフリーズ" |
| reference | 外部リソースの場所 | "ログは Grafana の X 板" |

詳細は次章の `CLAUDE.md` 設計術で扱います。

## 起動フロー（ざっくり）

```
[アプリ起動]
   ↓
~/.claude/settings.json を読む（権限・フック・ENV）
   ↓
~/.claude/CLAUDE.md を読む（グローバルルール）
   ↓
カレントプロジェクトの CLAUDE.md を読む（プロジェクトルール）
   ↓
カレントプロジェクトの memory/ を読む（前回までの引き継ぎ）
   ↓
チャット待機
   ↓
ユーザの指示
   ↓
モデル選択 + ツール選択 (MCP / Skill / Bash / Edit など)
   ↓
実行 → ユーザへ返答
```

## なぜ "Manus でなく Claude Code" なのか

| | Manus | Claude Code |
| --- | --- | --- |
| 構成 | すべて自社サーバで完結 | **外部サービスを連携** |
| 学習度 | 万能感はあるが裏側が見えない | **GitHub / Vercel / Supabase の解像度が上がる** |
| カスタマイズ | 内部に閉じる | `CLAUDE.md` / Skill / MCP で **無限に拡張** |

> 「Manus は便利だが、開発の知識は身につかない。
> Claude Code は外部サービスを連携するから、**裏側の解像度が上がる**」
> — 薄井 匠
