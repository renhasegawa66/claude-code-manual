# 名言集

講座の中で薄井匠氏が放った印象的なフレーズを **章別** にまとめました。
気に入ったものは `CLAUDE.md` や Slack のステータスに貼ってもいいかも。

## Claude Code の本質

> Claude Code は、**未来の働き方そのもの** だ。
> 経営者は、それを使っている人と使っていない人で発言の解像度がすぐにわかる。

> Manus は便利だが、開発の知識は身につかない。
> **Claude Code は外部サービスを連携するから、裏側の解像度が上がる**。

> 人間が AI を使いこなすのではない。
> **AI 組織が動き、人間は許可しますねポチを押すだけになる**。

## プロンプトの作法

> **プロンプトとは、理想と現実のギャップを埋めるもの。**
> それ以上でも以下でもない。

> タイトなリソースでクイックなローンチを目指す
> バイブコーディング AI スタートアップでのベストプラクティスは、
> **最初のプロンプト時点でのスペックの解像度**。
> ……と、ひいおばあちゃんが教えてくれた。

> 「あなたはプロの〇〇です」式のロールプロンプトは現代ではほぼ不要。
> **プロンプト集を漁るより、自分の理想を言語化することが本質**。

## 安全運用

> 自分の可能性は過信していい。
> **だが、セキュリティ周りは絶対に過信するな**。

> Bypass モードを使う気分は、
> ハンターハンターで主人公が自分の体を犠牲にして敵を倒すあのシーン。

> **Stripe を自作するみたいなバカなことを考えるな。**
> 決済・メール配信・EC は、世界が信頼している既存サービスに任せろ。

> **メール MCP は下書きまで。**
> 送信は人間がやる。これだけは守れ。

## 学び方

> 受動視聴の定着率は **5%**。
> 自分でやれば **75%**。人に教えれば **90% 以上**。
> どこを目指すかは自分次第。

> **エラー文言は、そのまま AI（チャット）にコピペすれば 99% 解決する。**
> これを **自走力（独学力）** と呼ぶ。
> これができないと Claude Code は正直使えない。

> 枠組みは人から学べ、**細かい部分は AI に聞け**。

## 美学

> **デスクトップの汚さは、品性の汚さ**。

> 常に **作り手** になりましょう。
> 作り手になることで、受け手としての感性も高まる。

> **クローンを作ってみると、本家のすごさがわかる。**

> 側はパクられる時代。
> **差別化は熱量とストーリーにしかない。**

## 比喩

> **MCP は調味料。Skill はレシピ。**
> 調味料を増やすほど、作れる料理が増える。

> Claude Code は **「博士の愛した数式」の博士** と同じ。
> 毎朝、服に書かれたメモを読んで「自分は誰か」を思い出す。
> そのメモが `CLAUDE.md` だ。

> GitHub は **ゲームのセーブ機能** だ。

> API は **ウェイター** だ。
> 客（アプリ）と厨房（サーバ）の間を取り持ってくれる。

## 経済・時代観

> **世界の GDP の 1.6% は Stripe で動いている。**

> Claude Code は確実に赤字でユーザー獲得フェーズ。
> PayPay の 20% 還元期と同じだ。
> **使い倒すなら、今だ。**

> 今、**人類が一番賢い時代** と、**人類以外が一番賢い時代** の
> 両方を体験できる、地球史で唯一の世代だ。
