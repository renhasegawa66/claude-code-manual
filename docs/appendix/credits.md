## 構築方法

このマニュアル自体が **Claude Code で構築されています**。

```
1. 講座の VTT 文字起こし（合計 14,000 行）を
   2 つのチームエージェント並列で要約抽出
2. VitePress で静的サイトとして構造化
3. GitHub にプッシュ
4. Netlify で自動デプロイ
```

つまり、このマニュアル自体が本マニュアルで紹介している
**「ローカル → GitHub → 自動デプロイ」** のワークフローの実例です。
