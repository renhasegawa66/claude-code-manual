# 5. 実演デモ集

ライブ講座で実演された 11 個のデモを **そのままなぞれる形** で再構成しました。
それぞれ "プロンプト → 何が起きる → 何を学ぶか" の 3 段で読めます。

::: tip 共通の前提
- いずれも **空のフォルダ** または `~/dev-projects/<案件名>/` で実行してください。
- プロンプトは **音声入力前提** で書かれているので、誤字脱字があっても文脈で通ります。
:::

## デモ 1 — タイマーアプリ

::: code-group
```text [プロンプト]
簡単なタイマーを作ってください
```
:::

- 指定したフォルダ直下に `index.html` が生成され、ブラウザで動く
- **学ぶこと**: ChatGPT と違いコードを **手作業でコピペ・保存しなくても、PC 上に直接配置される** こと
- 開いた URL は `file://` または `localhost` で **自分の PC 専用**。他人には共有できない（後述のデプロイ章で公開する）

## デモ 2 — デスクトップを散らかして整理させる

::: code-group
```text [① 散らかす]
デスクトップに適当な大量ファイルを30個ばらまいて散らかしてください
```
```text [② 整理する]
散らかしたファイルを綺麗に整理整頓してください
```
:::

- 種類別（プライベート／メモ／開発／仕事／ダウンロード 等）に **自動分類**
- **学ぶこと**:
  - Claude Code が "特定フォルダ内で動く" こと
  - 複数形式のファイルを生成できること
  - 内容を読んで分類できること

## デモ 3 — 名刺画像 → Excel

::: code-group
```text [プロンプト]
cards フォルダ内の名刺情報を読み込み、すべての名刺情報を
Excel に整理してください。Excel ファイルをアウトプットしてください。
```
:::

- 配布リポジトリから名刺画像 20 枚を `git clone` で取得しておく
- 写真スキャン → 文字認識 → 一括 Excel 化を **全自動**
- **学ぶこと**: OCR と表データ生成が 1 プロンプトで通ることのインパクト

## デモ 4 — 領収書のリネーム + 一覧化

::: code-group
```text [プロンプト]
Receipts フォルダの領収書を、先ほどの名刺と同じ形式で
Excel にまとめてください。
さらに各領収書のファイル名を
"YYYYMMDD_クライアント名（会社名）_但し書き"
の形式に変更してください。
```
:::

- **想定ユースケース**: 確定申告、税理士への提出資料整理
- **学ぶこと**: **命名規則** を指示に含めると後工程が圧倒的に楽になる

## デモ 5 — タスク管理アプリ（中規模開発）

::: code-group
```text [プロンプト]
シンプルなタスク管理アプリを作ってください
```
:::

- Claude 側が **要件が曖昧だと判断** すると、ユーザに逆質問してくれる
  - Web / ネイティブ？
  - ログイン要否？
  - リマインダー要否？
- 完成までおおむね 10〜15 分
- **学ぶこと**: 最初の解像度が低くても、AskUserQuestion で詰めれば事故が減る

## デモ 6 — 生成画像 → UI 模倣

::: code-group
```text [プロンプト]
UI は添付した画像のものを限りなく模倣してください。
全く同じものにしてください。
```
:::

1. ChatGPT の **Image gen 2.0** で「タスク管理 UI のイメージ画像」を生成
2. 画像をダウンロード → Claude Code チャット欄にドラッグ&ドロップ
3. 上のプロンプトを送る

- **学ぶこと**: UI モックを画像で投げると、**それっぽい UI を一発で書いてくれる**

## デモ 7 — Notion クローン / Slack クローン

- 過去に作ったものをローカルで起動して見せる回
- **学ぶこと**: **「クローンを作ると本家のすごさがわかる」**
- 注意: SNS で「Notion クローン作った」のような発信は控える方が無難

## デモ 8 — Google Calendar MCP

::: code-group
```text [プロンプト]
Google Calendar と連携して一週間分の予定を教えてください。
および 1 時間の Zoom 会議ができる空き時間を教えてください。
```
:::

- 事前準備: 設定 → コネクタ から **Google Calendar** を接続
- 出力フォーマットも指定可（表ではなくプレーンテキスト、など）

## デモ 9 — Gmail MCP で 20 件の下書き一括生成

::: code-group
```text [プロンプト]
名刺 Excel から会社名・役職を読み、業界を推察してください。
それぞれの業界向けに AI 研修提案のメールを20通分、
Gmail の "下書き" として作成してください。
（送信はしないでください）
```
:::

::: warning 送信は絶対にしない
**メール MCP は "下書きまで"** が鉄則です。誤送信は取り返しがつきません。
:::

## デモ 10 — Skill による PPTX 一発生成

事前に「道草スタイル PPTX 生成スキル」を取り込んでおく。

::: code-group
```text [プロンプト]
/pptx_michikusa
このメモを元に 100 枚のスライドを生成してください。
（メモを貼り付け）
```
:::

- 100 枚規模のスライドが **1 プロンプトで仕上がる**
- **学ぶこと**: Skill は **再利用可能な一連の手順** を `/<skill名>` で呼べるようにする仕組み（[7 章 Skills](/beginner/07-skills) で詳述）

## デモ 11 — チームエージェント（並列リサーチ）

::: code-group
```text [プロンプト]
"薄井匠" についてリサーチしてください。
その際チームエージェントを組んで、以下 4 つの並列エージェントで
進めてください:
- SNS からの調査
- Web 記事からの調査
- YouTube からの調査
- Wikipedia からの調査
```
:::

- Claude が **4 つの専門エージェントを生成 → 並列実行 → 結果統合**
- **学ぶこと**: 1 人の Claude が 1 タスクを抱える働き方から、**Claude が部下の Claude を編成する** 働き方へ
- 詳細は [8 章 チームエージェント](/beginner/08-team-agents)
