## モデル早見表

| モデル | 立ち位置 | 速度 | 賢さ | 推奨用途 |
| --- | --- | --- | --- | --- |
| **Claude Opus 4.7** | 最高峰 | 普通 | ★★★★★ | 難しいバグ修正・大規模設計・ここぞ |
| **Claude Sonnet 4.6** | バランス | 速い | ★★★★ | **本マニュアル標準推奨** |
| **Claude Haiku 4.5** | 最速 | 最速 | ★★★ | 簡単なファイル操作・`git clone`・パス確認 |

::: tip コンテキストの上限
Opus 4.7 には **1M（100万）トークン版** があり、約 75 万字 = 数百ページの仕様書を一括で読み込めます。長尺タスクなら最初から 1M 版を選ぶのが安全。
:::

## 講師の使い分け

```
簡単  → Haiku
普通  → Sonnet 4.6 ← 迷ったらこれ
重い  → Opus 4.7
```

### Pro プランの場合

普段は **Sonnet 4.6** を温存運用し、ここぞというときに Opus を使う。

> 「Opus は温存して Sonnet で操作する」（p.61）

### Max プランの場合

**Opus をバンバン使ってよい**。

::: tip Anthropic 創業者の見解
「Haiku → Sonnet → Opus と出戻りでやり直すくらいなら、
**最初から Opus** の方が結果的にコスパが良い」

→ 失敗のリスクが高いタスクなら、ケチらず Opus にしましょう。
:::

## モデル切り替え

| 操作場所 | 操作 |
| --- | --- |
| Desktop 版 | 右下のモデル名をクリック → 一覧から選択 |
| CLI 版 / 共通 | 入力欄で **`/model`** と打って一覧表示 → 選択 |

> 「Desktop 版は楽ですね！」（p.66）

## 使用状況の見方

モデル名をクリックすると **プラン使用状況パネル** が開きます。
あるいは入力欄で **`/context`** を実行すると、右下にコンテキスト使用量バーが常時表示されます。

| 項目 | 意味 |
| --- | --- |
| 5 時間制限 | 直近 5 時間の上限 |
| 週制限 | 7 日合計の上限 |
| リセット時刻 | 次にカウンタがクリアされる時刻 |

> Opus 連発でクレジットは一瞬で溶けます。
> "重い作業の前にはここを必ず見る"。

## コンテキスト ≒ AI の記憶力

| モデル | コンテキスト上限 |
| --- | --- |
| 標準 Opus / Sonnet / Haiku | 200K トークン |
| **Opus 1M 版** | 1,000K トークン |

長尺の連続タスク（動画編集／大規模リファクタ など）は **1M 版 Opus** を選ぶと
途中で記憶を失わずに完走できます。
コンテキストを使い切ったら **`/compact`** で要約圧縮も可能（[11 章 便利コマンド集](/beginner/11-commands) 参照）。
