# 8. チームエージェント — 並列マルチエージェント

## 概念

  <img src="/slides/beginner/page-104.jpg" alt="チームエージェントの仕組み">
  <figcaption>1 体の Claude から複数のサブエージェントへ枝分かれする（p.104）</figcaption>
</figure>

**チームエージェント** は、Claude Code に
**「複数の専門エージェントを編成して、並列で動かせ」** と指示すると、
Claude 自身が役割分担を考えて **複数の部下 Claude を起動** してくれる機能です。

```
あなた → 1 人の Claude（マネージャ）
              ├─ Claude（SNS 調査担当）
              ├─ Claude（Web 記事担当）
              ├─ Claude（YouTube 担当）
              └─ Claude（Wikipedia 担当）
```

スライド原文：

> Claude が分裂し、目的遂行のためのチームを作る
>
> - 例：A が YouTube、B が SNS、C が Web 記事を担当
> - **並列で調査するため 3 倍のスピード**
> - 実践：特定の人物についてリサーチするチームを作る

::: tip これが講師の言う "未来の働き方"
1 人の人間 → AI 1 体に作業を頼む、ではなく
1 人の人間 → AI 組織（チーム）に **「ビジネスを動かしておいて」** と頼む、という構造への移行。
:::

## 基本プロンプト

::: code-group
```text [リサーチ系]
"<対象>" についてリサーチしてください。
チームエージェントを組んで、以下 4 つの並列エージェントで
進めてください:
- SNS からの調査
- Web 記事からの調査
- YouTube からの調査
- Wikipedia からの調査
最後に統合レポートを 1 つにまとめてください。
```
```text [リサーチ + 制作系]
新しいランディングページのコンセプトを 3 案作りたい。
以下 3 つを並列エージェントで進めてください:
- 競合 LP の調査担当
- ターゲット顧客像のリサーチ担当
- 文言案を 3 パターン書くコピーライター担当
3 担当の出力を統合し、最後に 1 ページ HTML を組んでください。
```
:::

## 応用 — AI 組織の例

講師が "AI 目標会" の運営想定で挙げた構成：

| エージェント | 役割 |
| --- | --- |
| 教育者 AI | 既存コンテンツを見て、次に作るべきコンテンツを提案 |
| 調査班 AI | 実際のコンテンツを作成 |
| スライド生成 AI | 講座用 PPTX を生成 |
| 動画クリエイター AI | スライドから動画を作成（音声付き） |
| PR 担当 AI | メルマガでユーザーに告知 |
| エゴサくん AI | SNS の言及を収集 |
| マーケター AI | エゴサ結果からマーケ施策を組成 |

これらを **定期実行** にすれば、"AI 組織が会社の OS になる" 状態に近づきます（応用編 [Routines](/advanced/08-mcp-advanced)）。

## エージェント同士の会話を見る

エージェント間の通信を **Slack（自作 Slack クローン）に流す** と、
AI 同士がチャットしている様子が "見える化" できます。

> 「人間って何なんだろう、と感じるレベル」 — 薄井 匠

## 人間の役割は何が残るのか？

講師の整理：

1. **ビジネス設計**（何を作るか）
2. **承認のポチ**（OK を出すだけ）
3. **目利き**（出てきたものの品質判断）

逆に言えば、上記以外は **AI 組織で代替可能** という前提で設計し始めるのが現実的、という主張です。

## チームエージェントを呼び出すコツ

- **役割を箇条書きで明示する**（"○○ 担当" "△△ 担当" のように）
- **最終成果物の形** を指定する（"統合レポートを 1 つ" "1 ページ HTML" 等）
- **並列で良い** ことを明示する（"並列エージェントで"）

::: warning 大きすぎるタスクは分割
1 体の Claude が抱えるとコンテキスト 200K を超えがちです。
**仕事を細かく切ってチームに配る** ことで、各員のコンテキストに余裕を持たせられます。
:::

## 実習アイデア

> 「自分の好きな人物や会社についてリサーチをしてみよう」（p.107）

たとえば：
- 気になる起業家の経歴
- 競合企業の最近の発信
- 自分の業界の動向まとめ

を、4 並列エージェントに割り振ってリサーチ → 統合レポートを作らせると、
チームエージェントの威力が一発で体感できます。
