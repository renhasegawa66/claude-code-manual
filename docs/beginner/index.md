# 初級編 — はじめに

このパートでは、Claude Code を **「初めて起動するところから、便利な機能をひと通り使えるようになるまで」** を 10 章で解説します。

<div class="section-quote">
「<strong>Claude Code は未来の働き方そのものだ。</strong>経営者は、それを使っている人と使っていない人で発言の解像度がすぐにわかる」<br>— 薄井 匠
</div>

## 本パートのゴール

1. Claude Code が **何者で、他の AI と何が決定的に違うか** を一言で説明できる
2. デスクトップアプリを **安全に起動し、最初のファイルを生成できる**
3. **権限モード／モデル** を場面に応じて切り替えられる
4. **MCP（外部連携）／Skills（手順書）／チームエージェント（並列）** の概念を区別できる
5. 「何ができないか」と「やってはいけないこと」が言える
