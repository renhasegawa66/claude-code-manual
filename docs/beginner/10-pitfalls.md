# 10. 落とし穴と安全運用

::: danger 最重要
Claude Code はあなたの PC のファイルを **読み・書き・消し・実行できます**。
本ページの内容は "知っているか・知らないか" で **後日の損失額が桁違いに変わります**。
:::

## 1. 権限まわり

### やってはいけない

- **PC 全体（ルート）への権限付与**
- **ホームディレクトリ全体への Bypass モード**
- **Bypass モードで `rm` や `git push` を含む操作**

### やるべき

- **空のフォルダ／プロジェクト単位** で権限を渡す
- **大規模操作は Plan モードで計画を確認** してから実行
- `Bypass` は **小規模で取り返しのつく作業のみ**

## 2. 料金まわり

| 落とし穴 | 対策 |
| --- | --- |
| 無料プランで使い始めようとする | **無料では一切動かない**。Pro 以上が必須 |
| Pro で長尺ハンズオンに突入 | 制限到達リスク。長尺は **Max** で |
| Opus を全タスクで連発 | 軽い作業は **Sonnet / Haiku** に降ろす |
| 使用量を見ないまま走る | 重い作業前に **必ず使用状況を確認** |

## 3. GitHub / 他人のコード

::: warning Skill / リポジトリの取り込み
Claude Code は **GitHub からのインストールを止めてくれません**。
信頼できない人のリポジトリを取り込むと、**マルウェアを自分のホームに撒く** ことになりかねません。

**判断基準**:
- 信頼できる人（知人・コミュニティ）の紹介経由
- もしくは **Star 1,000 以上**（≒ Google マップ "500 件レビュー 4.2" の信頼度）
:::

## 4. メール送信は絶対にしない

```diff
- "下書きを作って、送信もしておいてください"
+ "下書きまで作成してください。送信は私が手動で行います"
```

**Gmail MCP は権限の範囲で送信もできます。**
誤送信を防ぐため、運用ルールとして **"送信は人間"** に統一しましょう。

## 5. コンテキスト枯渇

- 標準モデルは **200K トークン** で記憶を失う
- **AI が同じことを聞き返す** / **過去の指示を忘れる** ような兆候が出たら危険信号
- 対策:
  - 長尺は **1M モデル**（Opus 1M）
  - 区切りで **新セッション** を立てる
  - 重要前提は `CLAUDE.md` に置く（[応用編 2 章](/advanced/02-claude-md)）

## 6. ファイル所在の見失い

Claude Code は **指定フォルダ内のどこかに自由にファイルを置きます**。
作業後に "どこに保存された？" がわからなくなりがち。

::: tip 対策
1. **保存後に必ず "ファイルパスを出して" と聞く**
2. Mac の場合: <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>G</kbd> でパスを直接ペースト → ジャンプ
3. Finder からパスを渡したい時: ファイルを <kbd>Option</kbd> 押しながら右クリック → **「パス名をコピー」**
:::

## 7. "デモアプリを世界に公開" の事故

ローカルで動くものは安全ですが、応用編で扱う **デプロイ** を急ぐと事故が起きます。

| 起こりうる事故 | 防ぎ方 |
| --- | --- |
| API キーを GitHub に push してしまう | `.env` を必ず `.gitignore` に追加（応用編 [6. APIキーとセキュリティ](/advanced/06-security)） |
| Supabase の RLS 未設定 → 個人情報が外部閲覧可 | 公開前に **必ず RLS を設定**（応用編 [7. フロント／バック分離と Supabase](/advanced/07-fullstack)） |
| マイナンバー等を扱う本番デプロイ | **やらない**。家族・友達に見せるレベルまでに留める |

## 8. AskUserQuestion の UI バグ

直近、AskUserQuestion 実行時に右側に変なタブが出るバグが発生中（Anthropic 修正待ち）。
回避策：ブラウザでのタブ移動などで進められます。

## 9. 過信のリスク（まとめ）

> 「自分の可能性は過信していい。
> **だが、セキュリティ周りは絶対に過信するな**」
> — *薄井 匠*

Claude Code は理屈上、以下を **やりかねません**：
- ファイル全消し
- 勝手にメール送信
- セキュリティガバガバな状態で世界公開
- API キーを GitHub に流出
- 大金が動く API（取引・決済）を**勝手に実行**

**だからこそ**、応用編に入る前に上記 8 個を体で覚えてください。
