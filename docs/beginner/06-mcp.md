# 6. MCP — 外部サービス連携

## MCP とは

**MCP（Model Context Protocol）** は、Claude Code と **外部サービス** を繋ぐための標準規格です。

<figure class="slide-figure">
  <img src="/slides/beginner/page-089.jpg" alt="MCP による外部ツールとの連携図">
  <figcaption>Claude Code を中心に Notion / Google / Slack 等と放射状につながる（p.89）</figcaption>
</figure>

- Google Calendar, Gmail, Slack, Notion, GitHub, Google Drive …
- API コネクタと **ほぼ同義** で覚えて OK
- Claude Code 専用ではなく、ChatGPT / Manus など他 AI でも同じ概念

::: tip 比喩で覚える
- **MCP = 調味料**（できることの幅を増やす道具）
- **Skill = レシピ**（一連の手順書）

つまり、MCP で道具を揃え、Skill で再現可能な料理を作るイメージです。
:::

## MCP を追加する

1. 画面左下の **歯車** → 設定
2. **コネクタ** タブ
3. **「コネクタを参照」** ボタン
4. 一覧から追加したいサービスを選択
5. 各サービスの OAuth ログインを完了

## 接続状況を確認 — `/mcp`

入力欄で **`/mcp`** を打つと、現在接続中の MCP 一覧が表示されます。
**緑のチェック** が付いていれば接続済み。

```
/mcp
```

接続が落ちている場合は、再度 OAuth を踏み直すか、Claude Code を再起動するのが手っ取り早いです。

::: tip 接続エラーで詰まったら
> 「接続エラー起きても頑張ろう」（p.93）— 接続まわりはバージョンで挙動が変わりがちなので、エラー文をそのまま AI に貼って原因を推定させるのが速い。
:::

## 日本人ユーザにとって有用な MCP

| MCP | できること |
| --- | --- |
| **Google Calendar** | 予定取得、空き時間検索、招待作成 |
| **Gmail** | 下書き作成、ラベル管理、スレッド検索（**送信は禁止運用が安全**） |
| **Slack** | メッセージ取得、投稿、リアクション、今日の発言ログ取得 |
| **Notion** | ページ作成、データベース操作、タスク管理 |
| **GitHub** | リポジトリ操作、Issue/PR 作成（応用編で詳述） |
| **Google Drive** | ファイル一覧・取得・アップロード |
| **Supabase** | DB / 認証（応用編で詳述） |
| **Playwright** | ブラウザ自動操作・動作テスト（応用編で詳述） |

## 使い方の感覚

MCP を入れたあとは、特別なコマンドはほとんど不要です。
**普通に日本語で頼むだけ** で、Claude が必要な MCP を選んで使ってくれます。

::: code-group
```text [Calendar 例]
今週の Zoom 会議を全部教えてください。
空き 1 時間枠で、午前中のものだけリストにしてください。
```
```text [Gmail 例]
"AI 目標会" でラベル付けされた未読メールを全部読んで、
内容を 3 行で要約してください。返信は下書きまで。
```
```text [Notion 例]
"道草ノート" の今週ページに、本日のタスクを箇条書きで追記してください。
```
:::

::: tip パーソナライズメール
「Google MCP で **Gmail の下書き** を作れるということは、各相手にパーソナライズしたメールを大量に作れる、ということ」（p.92）。
名刺 Excel × 業界推察 × Gmail 下書きで、20 通のオーダーメイド営業メールが数分で揃います。
:::

## ハマりポイント

::: warning メールは送信させない
**Gmail MCP は権限の範囲で送信もできてしまいます**。
誤送信が一番怖いので、運用ルールとして **"下書きまで"** に統一してください。
プロンプトにも明示するのが安全です。
:::

::: warning 接続するアカウントを間違えない
個人アカウントと業務アカウントを両方ログインしている場合、
意図しない方の Calendar / Gmail を触ってしまう事故があります。
**最初に "どのアカウントに接続しているか" を Claude に確認させる** クセを付けましょう。
:::

## "PC のキッチンに調味料を増やす"

講師の比喩：

> 「Claude Code 単体は包丁とまな板。
> MCP は塩・胡椒・醤油。
> Skill はレシピ。
>
> 調味料を増やすほど、作れる料理が増える」
